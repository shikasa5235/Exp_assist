## 1. 依頼された修正 2件

### 【1】help-warn-flash-short の参照先を作った

ストロボ側の光量不足とアンビエント側の光量不足を分離した。

| 条件 | helpId |
| --- | --- |
| フル発光でも届かない（over < 0） | `help-warn-flash-short` |
| 光は足りるが上限（強い側）で使えない | `help-power-ceiling` |
| ISO上限・レンズ開放でも足りない（アンビエント側） | `help-warn-light-short` |

文言:

- フル発光でも◯段 足りません（到達◯m／設定◯m）。距離を◯mまで詰める／ISOを◯段上げる／Fを◯段開ける
- 上限◯ では◯段 足りません。距離を◯mまで詰める／ISOを◯段上げる
- 光量が◯段足りません。開放を明るく、または三脚が必要です

「到達距離 < 設定距離」は数学的に over < 0 と同値なので1つの警告で表現している
（over = 2·log2(gnFull/(N·d))、reach = gnFull/N より over < 0 ⟺ reach < d）。

HELP は 17 値。§0.5 が要求する helpId は 19 件（17 ＋ 注記の help-calibration・help-flash-basics）。

### 【2】発光量の過剰決定の対応先

「1/32 では 1.9段 強すぎます」は `help-power-mode`（§10）。
§10「発光量と距離の両方を決めたとき」に読み方と3案の表を追記した。

| 案（強すぎるとき） | 効果と副作用 |
| --- | --- |
| 表示された距離まで下がる | 段数ぶん暗くなる。背景の明るさは変わらないので最も安全 |
| F を◯段絞る | ストロボも背景も同じだけ暗くなる |
| ISO を◯段下げる | 同上。背景も暗くなる |

足りないときは逆向き（距離を詰める／F を開ける／ISO を上げる）。

### §0.7 スタイル規則への適合

- 本文 15px/400・行高 1.6、見出しは h4 15px/600・h3 17px/600
- 数値は .num で --font-num ＋ tabular-nums
- 装飾なし。画像・図版ゼロ
- 表はすべて2列。3列だった表（意図／効く・効かない／経路比較／警告レベル）は2列に組み替えた
