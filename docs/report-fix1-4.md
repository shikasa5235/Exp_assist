## 修正1：help-power-ceiling が到達不能だった原因

**到達可能な分岐でした。テストのシナリオが範囲外だっただけです。**
警告そのものの削除や条件の緩和は不要でした。

### 確認した4点

| 確認 | 結果 |
| --- | --- |
| 1. powerCeilingStops が設定されているか | 設定されていた（テストは 3 を明示） |
| 2. powerMode が auto か | auto だった |
| 3. 不等号の向き | 正しい。`shortStops = max(0, ceilingStops − over)` で「必要発光量 < 上限」のとき正になる |
| 4. シナリオの距離 | **これが原因。** #33 の auto シナリオは 16.5m / 40m / 0.5m の3つで、0 ≦ over < ceiling を満たすものが無かった |

- 距離 16.5m は over ≈ −0.0027（わずかに負）→ `help-warn-flash-short` に入る
- 距離 40m は over ≈ −2.56 → 同じく flash-short
- 距離 0.5m は over ≈ 10 → `help-warn-flash-strong`

`#37` は距離 = GN_iso / F で over = 0 ちょうどなので ceiling 分岐に入るが、
`#33` は自前のシナリオ配列しか収集しないため到達しなかった。

### 対応

`#33` に上限到達シナリオを追加した（上限2段・距離 11.65m → over = 1 → 不足1段）。
あわせて `#39` を新設し、同じ条件を独立したテストとしても固定した。

なお `over` が 0 付近で誤って flash-short 側に落ちないよう、判定は `over < -1e-9` にしている。

## 修正2：発光量チップに 1/4 を追加

| 変更 | 内容 |
| --- | --- |
| チップの選択肢 | おまかせ / **1/4** / 1/8 / 1/16 / 1/32 / 1/64 / 1/128 |
| 1/2・1/1 | チップに出さない（閃光時間 1/400・1/250 で被写体ブレの領域）。おまかせ経由でのみ到達 |
| powerCeilingStops 既定 | 3（1/8） → **2（1/4）** |
| 設定タブ | 従来どおり変更可能 |

### 1/4 と閃光時間の関係（マニュアル §10 に表を追加）

| 発光量 | 閃光時間 | 止まる被写体 |
| --- | --- | --- |
| 1/4 | 1/700 | 走る人（1/500）まで止まる |
| 1/2 | 1/400 | 歩く人（1/250）が限界 |
| 1/1 | 1/250 | 静物のみ |

1/4 では走る人（1/500）が止まるため閃光時間の警告は出ない。
より速い被写体（スポーツ 1/1000、車 1/2000）では出る。判定は既存の freezeWarning がそのまま担う。

### 追加テスト

- **#38** 発光量 1/4 固定 → 推奨距離 8.24m（GN_eff = 46.60 × 2^-1 = 23.30、23.30 ÷ 2.8284）
- **#39** auto / 上限 1/4 / 距離 11.65m → alert「上限 1/4 では 1段 足りません」＋ helpId = help-power-ceiling

## 修正3：モディファイアを実機に合わせた

| モディファイア | 減光段数 |
| --- | --- |
| 標準リフレクター | 0.0（基準） |
| AK-R1 ドームディフューザー | 1.5 |
| オクタ 30cm | 1.5 |
| オクタ 60cm | 2.0 |
| オクタ 90cm | 2.5 |

既存のアンブレラ・ソフトボックス・ビューティディッシュ・ベアバルブは削除した。

### 校正をモディファイアごとに保存する構造へ変更（重要）

**指摘のとおり、既存の uncalibrated 判定はモディファイアの切り替えに追従していませんでした。**
プロファイルに `calibrated: boolean` を1つ持つだけだったため、標準リフレクターで校正すると
オクタに切り替えても「校正済み」のままでした。仕様 §5.2 の
「校正値はプロファイルごと・モディファイアごとに保存」を満たしていない状態でした。

| 変更前 | 変更後 |
| --- | --- |
| `profile.k` と `profile.calibrated` | `profile.k`（推定の基準）＋ `profile.cal = { modifierKey: 実測k }` |
| 校正すると calibrated = true | 校正するといま選択中のモディファイアのキーに k を保存 |
| モディファイア切替で変化しない | 未校正の組み合わせでは推定 k に戻り「推定値」バッジが出る |

compute 側は `kFor(prof, modifier)` と `isUncalibrated(prof, modifier)` で参照する。
設定タブのボタン文言も「このモディファイアで再校正」に変わる。

### 追加テスト

- **#40** 標準リフレクターで k=2.33 校正済み → オクタ60cm に切替
  → フル発光到達がオクタの2段減光ぶん落ち、かつ uncalibrated = true・推定値バッジあり

#38 と #40 はどちらも 8.2m になるが**経路は独立**（#38 は発光量2段落とし、#40 はモディファイア2段減光）。
期待値もそれぞれ別に導出しており、片方が他方を呼んでいない。

## 修正4：ブラックミストを光学フィルターとして追加

| 項目 | 実装 |
| --- | --- |
| state | `filters.blackMist: boolean`（既定 false） |
| 定数 | `BLACK_MIST_STOPS = 0`、上限 `1/3`。設定タブで 0〜0.33段に調整可 |
| solveND | **探索対象に入れない**（0段の要素は解の質を変えず冗長な解を生むだけ） |
| 減光の適用 | ndStops に加算。アンビエントとストロボの両方に効く（レンズ前なので ND と同じ） |
| 枚数 | **数える。** ケラレ警告（3枚以上）の対象 |
| 表示 | `ND2+ND16 + ブラックミスト`（ND と光学フィルターを分けて表記） |
| UI | 計算タブの ND チップ列に、区切り線＋破線枠のトグルとして追加 |

### 警告文

    フィルター3枚（ND2+ND16 + ブラックミスト）。24mm では周辺が落ちる可能性があります

焦点距離は state.focal を読むので、24mm 設定時にその値が入る。

### 追加テスト

- **#41** ND8 ＋ ブラックミスト → 合計3段 / 2枚 / ケラレ警告なし
- **#42** ND2+ND16 ＋ ブラックミスト → 合計5段 / 3枚 / ケラレ警告あり（「3枚」「24mm」を含む）

### 仕様との差異（報告）

指示は「かんたんタブ・計算タブの ND チップの並びに追加」でしたが、
**かんたんタブには ND チップが存在しません**（ND の装着操作は計算タブのみ、
所有 ND の管理は設定タブ）。計算タブに追加しました。
かんたんタブにも ND チップが必要なら指示をください。
