## ③ 拡張ISO をトグルで切り替える

| 項目 | 実装 |
| --- | --- |
| state | `camera.allowExpandedIso: boolean`（既定 **false**） |
| false | ISO の下限は `camera.isoMin`（200） |
| true | ISO の下限は `camera.expandedISOMin`（50） |
| 置き場所 | **かんたんタブ**（意図チップの下）と**計算タブ**（ND チップの直下）。設定タブではない |
| ラベル | 「拡張ISO（50〜）を使う」 |
| 連動 | 同じ state を見るので、どちらから変えても双方向に連動 |

既存の設定値名は変えていません（指示の `isoBase` / `isoMinExpanded` は、実装では
`camera.isoMin` / `camera.expandedISOMin` に対応します）。

### 効く範囲

`isoFloorOf(st)` を1箇所に定義し、**意図別ロジックの起点・クランプの下限・日中シンクロで使う ISO**
のすべてから参照するようにしました（17箇所）。

### 警告の連携

    OFF: 「拡張ISO（50〜）を使えば ND 1枚で済みます（画質低下の可能性あり）」  ← info を出す
    ON : 出さない（すでに使っているため）

文言を「ISO を拡張下限（50）まで下げれば…」から「拡張ISO（50〜）を使えば…」に変更し、
**トグルを入れれば解決するという行動**を指すようにしました。

### 既存テストへの影響（全件確認しました）

既定が `false` で、既存テストはすべて `allowExpandedIso` を指定していないため
`isoFloor = isoMin` となり、**期待値の変更は不要**でした。
`expandedISOMin` を前提にしていたのは #5b（`isoFloorWarning` の直接呼び出し）だけで、
これは純粋関数を直接呼ぶテストなのでトグルの影響を受けません。
