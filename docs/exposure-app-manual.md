# §0 組み込み仕様

## 0.1 設置場所

**ヘッダー右端の `?` ボタンから開く全画面シート。** タブにしない。別ページにしない。

| 判断 | 理由 |
| --- | --- |
| 4つ目のタブにしない | 固定結果パネルと衝突する。マニュアルの下に結果パネルは不要。320px で4タブは狭い |
| `help.html` に分けない | SW のプリキャッシュ対象が増え、アプリから離脱して再初期化が走る |
| 全画面シート | 読む間は計算画面を隠してよい。原則2は計算画面に対する原則であり、モーダルには適用しない |

## 0.2 マークアップの置き場所

本文は **`index.html` 内の静的 HTML** とする。`<body>` の**末尾**、アプリ本体の後に置く。

```html
<div id="manual" class="sheet" hidden role="dialog" aria-modal="true" aria-labelledby="manual-title">
  <header class="sheet-head">
    <h2 id="manual-title">使い方</h2>
    <button type="button" class="sheet-close" aria-label="閉じる">…</button>
  </header>
  <nav class="manual-index" aria-label="目次">…</nav>
  <div class="manual-body">
    <section id="help-intro">…</section>
    <section id="help-scene">…</section>
    …
  </div>
</div>
```

- JS の文字列テンプレートにしない。日本語の長文を JS 内に持つと編集と校正が困難になる
- `index.html` の**先頭側（アプリ骨格）は読みやすさを保つ**。だから末尾に置く
- 追加の JS は開閉制御のみ。本文の生成処理を書かない

## 0.3 開閉の挙動

| 項目 | 仕様 |
| --- | --- |
| 開く | ヘッダーの `?` ボタン、または警告の `?` ボタン |
| 閉じる | 右上の閉じるボタン / `Esc` キー / 背景のスワイプダウン |
| アニメーション | 下から 200ms / ease-out で `transform: translateY()`。`prefers-reduced-motion` では即時 |
| フォーカス | 開いたら閉じるボタンへ移動。シート内でフォーカストラップ。閉じたら呼び出し元へ戻す |
| スクロール | シート内のみスクロール。背後の body は `overflow: hidden` で固定 |
| 状態 | `state.ui.manual = null | 'help-xxxx'`。`setState` 経由で開閉する（再描画経路を増やさない） |
| 履歴 | `history.pushState` を使わない。ブラウザバックで閉じる挙動は実装しない（PWA でタブ状態と混ざる） |

## 0.4 目次

シート最上部に**セクション見出しのリスト**を置く。タップで該当セクションへスクロール（`scrollIntoView({ behavior: 'smooth', block: 'start' })`）。
`prefers-reduced-motion` では `behavior: 'auto'`。

アンカー指定で開いた場合は目次を飛ばして該当セクションを最上部に表示する。

## 0.5 警告からの導線（重要）

`advisor.js` の戻り値に `helpId` を追加する。

```js
// 変更前
{ level: 'warn', message: '…' }

// 変更後
{ level: 'warn', message: '…', helpId: 'help-sync-wall' }
```

- **`helpId` は必須フィールド**とする。全ての警告が必ずセクションを1つ持つ
- `advisor.js` は純粋関数のまま。文字列 ID を返すだけで DOM に触らない
- `ui.js` は `helpId` があれば警告の右端に `?` ボタンを描画し、押されたら `setState({ ui: { manual: helpId } })`

### 警告 → セクション 対応表

計算仕様 §9 の各警告に以下を割り当てる。

| 警告の条件 | `helpId` |
| --- | --- |
| SS < 手ブレ限界 | `help-warn-shake` |

| 必要 ISO > ISO上限 | `help-warn-light-short` |
| 必要 F < 開放F値 | `help-warn-light-short` |
| 必要 SS < 機種の最速（明るすぎ） | `help-nd` |
| F > 11（回折） | `help-warn-diffraction` |
| ISO > 上限の 1/2 | `help-warn-high-iso` |
| SS ≧ 1/2 秒（三脚推奨） | `help-warn-tripod` |
| 同調速度超過（HSS 非対応） | `help-sync-wall` |
| 同調速度超過（HSS off） | `help-sync-wall` |
| HSS 損失 > 4段 | `help-sync-wall` |
| ND 装着でストロボが減光 | `help-flash-basics` |
| 必要発光量 < 最小発光量（強すぎ） | `help-warn-flash-strong` |
| 必要発光量 > 1/1（光量不足） | `help-warn-flash-short` |

| 警告なし（この設定で撮れます） | `helpId` なし（`?` を出さない） |

# §1 このアプリについて

## できること

いまの光の状態と「どう撮りたいか」を選ぶと、F値・シャッター速度・ISO・ストロボの発光量を計算します。
数字を出すだけでなく、**その設定で何が問題になるか**（手ブレする、光が届かない、絞りきれない）を段数付きで教えます。

電波がなくても動きます。すべての計算は端末の中だけで行われ、通信は一切しません。

## 3つの画面

| タブ | 使う場面 |
| --- | --- |
| **かんたん** | シーンと撮りたい雰囲気を選んで、設定を出してもらう。通常はこれだけで足ります |
| **計算** | F値・SS・ISO のうち2つを自分で決めて、残り1つを出す。等価露出の一覧も見られます |
| **設定** | 手持ちの機材を登録する。ストロボの校正もここ |

## 数値の性格について

このアプリが出す数字には**2種類**あります。

**厳密なもの** — 露出計算そのもの（F値・SS・ISO の関係、段数の差）。これは数式で決まるので誤差はありません。

**目安のもの** — シーンの明るさ（EV）、ストロボの出力から推定したガイドナンバー、HSS の光量ロス、モディファイアの減光、閃光時間。これらは機材や状況で変わります。**±1段程度はズレる前提**で使ってください。

目安の項目は画面上に「推定値」と表示されます。ストロボについては§9の校正で実測に合わせられます。

# §2 <a id="help-setup"></a>最初にやること

初回起動時に3画面の機材登録が出ます。**全部「あとで」で飛ばしても使えます。**
急いでいるときは飛ばして、落ち着いたときに設定タブで入れてください。

| 画面 | 入れるもの | 分からないとき |
| --- | --- | --- |
| カメラ | 同調速度 / SS の最速 / ベースISO / 実用ISO上限 | 既定値のまま |
| レンズ | 開放F値 / 常用焦点距離 / 手ブレ補正段数 | 開放F値だけ合わせれば十分 |
| ストロボ | 出力(Ws) / HSS対応 / モディファイア | 出力だけ合わせる |

**手ブレ補正段数は、公称値の6〜7割**を入れるのが実用的です。「5段補正」と書かれていても、
現場で実際に効くのは3段程度です。公称値をそのまま入れると、警告が出るべき場面で出なくなります。

設定はいつでも変更でき、変更するとその場で計算し直されます。

# §3 <a id="help-scene"></a>シーンの選び方

## 選んでから微調整する

シーンのタイルを選ぶと、そのシーンの明るさ（EV）が入ります。**この値は±1段程度の目安**です。
実際の光に合わせて、下の微調整スライダーで動かしてください。1/3段刻みで±2段まで動きます。

| 迷ったら | 選ぶもの |
| --- | --- |
| 影がくっきり出ている | 快晴・順光（EV15） |
| 影の輪郭がやわらかい | 晴れ・薄曇り（EV14） |
| 影が出ていない | 曇り（EV13） |
| 建物や木の陰にいる | 厚い曇り／建物の日陰（EV12） |

**影の状態を見るのが一番確実です。** 空の見た目より正確に判断できます。

## 微調整の使い方

撮った結果が明るすぎた／暗すぎたときは、その差ぶんだけスライダーを動かします。
1段暗かったなら +1.0、1/3段だけ明るかったなら −0.3 です。

同じ場所で撮り続けるなら、最初の1枚で微調整を決めてしまえば以降は合います。

# §4 <a id="help-intent"></a>撮りたいものから決める（かんたんタブ）

意図を選ぶと、アプリが「何を優先して何を犠牲にするか」を決めて計算します。

| 意図 | 何を固定するか | 犠牲になるもの |
| --- | --- | --- |
| **背景をぼかす** | F値を開放に固定 | 明るい場所ではSSが速くなりすぎる／暗所ではISOが上がる |
| **動きを止める** | 被写体に応じたSSに固定 | ISOが上がる |
| **風景をくっきり** | F8・ベースISOに固定 | SSが遅くなり三脚が必要になる場合がある |
| **夜・手持ち** | SSを手ブレ限界に固定 | ISOが大きく上がる |
| **日中シンクロ** | §6 参照 | — |
| **スローシンクロ** | §7 参照 | — |

## 結果の3案

結果は**主案＋代替2案**で出ます。3案はすべて**同じ明るさになる組み合わせ**です。

| 案 | 性格 |
| --- | --- |
| 主案 | 意図に沿った中庸な設定 |
| ブレを避ける | SSを上げてブレ警告を消す。そのぶんISOが上がる |
| 画質を優先 | ISOを下げる。そのぶんSSが遅くなる |

**ノイズとブレのどちらを取るか**という選択なので、現場の状況で選んでください。
成立しない案は表示されません（3案が常に出るわけではありません）。

# §5 <a id="help-flash-basics"></a>ストロボの基本 — 覚えておくと全部が分かる

ストロボを使うとき、**背景と主被写体は別々に決まります。** これがこのアプリの中核です。

| | 効くもの | 効かないもの |
| --- | --- | --- |
| **背景（アンビエント）** | F値・SS・ISO・ND | — |
| **主被写体（ストロボ）** | F値・ISO・距離・発光量・ND | **SS** |

## なぜSSがストロボに効かないのか

ストロボの発光は 1/250 〜 1/9000 秒で終わります。シャッターが開いている時間より短いので、
**SSを変えても被写体に届く光の量は変わりません。**

これを使うと、こういうことができます。

- **SSを速くする** → 背景だけが暗くなる。被写体の明るさはそのまま
- **SSを遅くする** → 背景だけが明るくなる。被写体の明るさはそのまま

つまり **SS は背景の明るさ専用のダイヤル**として使えます。日中シンクロもスローシンクロも、
原理はこれだけです。

> 計算タブでストロボをONにして、SSのトラックを動かしてみてください。
> **発光量のトラックだけが動きません。** これがこの原理そのものです。

## NDは両方に効く

一方、NDフィルターはレンズの前にあるので、**背景とストロボの両方を同じだけ暗くします。**
ND4（2段）を付けたら、ストロボの発光量も2段上げないと被写体が暗くなります。

> NDを足すと**4本すべてのトラックが同時に動きます。** SSのときと見比べると違いが分かります。

# §6 <a id="help-daylight-sync"></a>日中シンクロの手順

明るい屋外で、逆光や影に入った被写体をストロボで起こす撮り方です。

## 入力するもの

1. シーン（＋微調整）
2. 意図で「日中シンクロ」を選ぶ
3. ストロボ：使うプロファイル / モディファイア / **ストロボ→被写体の距離**
4. 背景の明るさ：既定は −1段（背景が1段暗く写る）

**距離はカメラからではなくストロボから被写体まで**です。オフカメラで使うと両者は別物になります。

## 背景の明るさの目安

| 設定 | 仕上がり |
| --- | --- |
| 0段 | 背景も被写体も適正。自然だが平坦になりやすい |
| **−1段** | 背景が少し落ちて被写体が浮く。最も使いやすい |
| −2段 | 背景がしっかり暗い。ドラマチック |
| −3段 | 背景がほぼ黒。夜のように見える |
| +1段 | 背景を明るく飛ばす。ハイキー |

## 画面の読み方

一番上に **「同調速度の壁：+○段」** が出ます。これが日中シンクロで最も重要な数字です。
0段なら何も考えず撮れます。正の数なら§6の対処が必要です。

その下にアンビエント側とストロボ側が並びます。

```
┌─ 背景 ─────────────┐  ┌─ 主被写体 ────────┐
│ F2.8  1/250  ISO200 │  │ 発光量 1/2  FEC −0.1│
│ ND2 + ND16 装着      │  │ 到達 5.0m（設定 3.0m）│
│ 背景は −1.0 段       │  │ 閃光時間 1/400       │
└────────────────────┘  └────────────────────┘
```

**到達距離が設定距離より大きければ光は届いています。** 小さければ足りません。

# §7 <a id="help-sync-wall"></a>同調速度の壁 — 何が起きているか

## 壁の正体

ストロボは**同調速度より速いシャッターでは使えません。** シャッター幕が写り込んで、
画面の一部に黒い帯が出ます。多くのカメラで 1/200〜1/250 秒です。

ところが晴れた屋外は明るすぎます。**絞りを開けたいのに、SSを上げられない。** これが壁です。

## 具体例

快晴（EV15）、ベースISO200、同調速度 1/250 のカメラで考えます。

このときの適正F値は **F16** です。しかし背景をぼかすために **F2.8** で撮りたい。
F16 と F2.8 の差は **5段**。これが「同調速度の壁：+5.0段」の意味です。

## 越える方法は2つ

アプリは**両方を計算して並べます。自動で選びません。**

| 経路 | やること | ストロボへの影響 |
| --- | --- | --- |
| **ND経路** | NDで5段減光し、SSは1/250に留める | ストロボも5段減光される |
| **HSS経路** | HSSに切り替えてSSを1/8000まで上げる | 基準損失2段＋超過5段＝**7段**の損失 |

先ほどの例（200Ws・標準リフレクター・ISO200）で比較すると、

```
            SS       ND          発光量   到達距離
ND経路     1/250    ND2+ND16     1/2      5.0m
HSS経路    1/8000   なし         1/1      2.5m   ← 2段不利
```

**ND経路のほうが2段有利で、届く距離が2倍になります。**

## どちらを選ぶか

| ND経路が向く | HSS経路が向く |
| --- | --- |
| 被写体との距離を取りたい | 動きを止めたい（SSを自由にしたい） |
| 発光量を抑えて連写したい | フィルターの着脱をしたくない |
| 光量に余裕がない | 光量に余裕がある／被写体が近い |

**ND経路の弱点は、SSが同調速度に固定されること**です。走る被写体を背景ごと止めたい場合、
1/250 では足りません。そのときはHSS経路を選びます。

## HSSの光量ロスについて

HSSは発光を細かく連続させて幕の動きに追従させる方式なので、**光がかなり失われます。**
損失は「基準損失＋同調速度からの超過段数」で計算しています。基準損失の既定は2段ですが、
**機種差が大きい**ため設定タブで 1.0〜2.5 の範囲で調整できます。

実測とズレていたら調整してください。テスト撮影で「計算より1段暗い」なら基準損失を1段増やします。

# §8 <a id="help-slow-sync"></a>スローシンクロの手順

暗い場所で、**背景の夜景をSSで拾いながら、主被写体をストロボで止める**撮り方です。

## 入力するもの

日中シンクロと同じ項目に加えて、

- **三脚を使うか** — 使うなら手ブレ判定を飛ばし、SSを30秒まで開放します
- **先幕／後幕** — 計算には影響しませんが、助言が変わります

## 手順

1. 背景の明るさ（既定 −1段）を決める
2. アプリがアンビエント側のSSを出す
3. 三脚なしなら手ブレ限界と比べ、割っていたらISOを上げて調整
4. ストロボ側の発光量が出る
5. **閃光時間の警告が出ていないか確認**（§9）

## 後幕シンクロについて

SSが 1/60 より遅くなると「後幕シンクロ推奨」が出ます。

先幕（シャッターが開いた瞬間に発光）だと、被写体が動いた場合に**残像が進行方向の前に伸びます。**
歩いている人の前方にブレが出るので不自然に見えます。後幕（閉じる直前に発光）なら残像が後ろに残り、
動きの流れとして自然になります。

# §9 <a id="help-flash-duration"></a>閃光時間 — フル発光では止まらない

## 落とし穴

スローシンクロで被写体を止めているのは、**SSではなく閃光時間**です。
ここを勘違いすると、SSをいくら調整しても被写体がブレます。

そして**発光量が大きいほど閃光時間は長くなります。**

| 発光量 | 閃光時間の目安 |
| --- | --- |
| 1/1（フル） | 1/250 |
| 1/2 | 1/400 |
| 1/4 | 1/700 |
| 1/8 | 1/1200 |
| 1/16 | 1/2000 |
| 1/32 | 1/3500 |
| 1/64 | 1/5000 |
| 1/128 | 1/9000 |

**200Wsをフル発光すると閃光時間は1/250秒程度**あります。走る人を止めるには 1/500 が必要なので、
これでは止まりません。「発光量1/1では閃光時間1/250。この被写体は止まりません」という警告が出ます。

## 対処

**距離を詰めて発光量を落とす**のが基本です。距離を半分にすれば必要な発光量は2段下がり、
閃光時間は 1/250 → 1/700 になります。

他の手段としては、ISOを上げる（発光量を下げられる）、F値を開ける（同じ）があります。
いずれも「発光量を下げる」ことが目的です。

> この表の値は機種差が大きい目安です。手持ちの機材の公称値が分かれば、そちらを信じてください。

---

# §10 <a id="help-nd"></a>NDフィルターの使い方

## 何段必要かは自動で出ます

必要な減光段数から、**手持ちのNDで作れる組み合わせ**をアプリが探します。
枚数が最少になる解を優先します。

| 必要段数 | 組み合わせ（ND2/4/8/16 所有時） |
| --- | --- |
| 1〜4段 | 1枚で足りる |
| 5〜7段 | 2枚 |
| 8〜9段 | 3枚 |
| 10段 | 4枚全部 |
| 11段以上 | 所有NDでは不可 |

所有しているフィルターは設定タブで変更できます。買い足したら追加してください。

## 枚数を減らしたい理由

ガラスを重ねるほど**ケラレ・色被り・フレア**が増えます。特に広角では周辺が暗くなります。
3枚以上になると警告が出ます。

## 2枚必要になったときの代案

ベースISO200のカメラで5段必要になると、ND2+ND16 の2枚重ねになります。
このとき **「拡張ISO（ISO100 や 50）まで下げればND1枚で済む」** という案が出ます。

拡張ISOは階調やノイズで不利になる場合があります。ガラス2枚の光学的な劣化と、
拡張ISOの画質低下、どちらを取るかの判断です。**アプリは両方を出すだけで、選びません。**

## NDはストロボにも効く

§5 のとおりです。ND4（2段）を付けたら、ストロボの発光量も2段上げる必要があります。
アプリは自動で計算に入れているので、表示された発光量に従ってください。

# §11 <a id="help-calibration"></a>ストロボの校正 — 精度を上げる

## なぜ校正が必要か

**Ws（ワット秒）は蓄積エネルギーであって、光の量ではありません。**
実際の明るさはリフレクター、モディファイア、発光管の効率で大きく変わります。
メーカーの公称ガイドナンバーも測定条件がバラバラで、そのままでは使えません。

そこでアプリは `GN = k × √Ws` という推定式を使い、**係数 k をテスト撮影1回で実測に合わせます。**
既定の k は 4.0（100Ws で GN40、200Ws で GN57）ですが、実際は 2.5〜3.5 に落ち着くことが多いです。

未校正のプロファイルには **「推定値」バッジ**が出ます。これが消えるまではズレる前提で使ってください。

## やり方（5分）

1. ストロボを**標準リフレクター**（またはいつも使うモディファイア）で設置
2. 被写体までの距離を測る。**3m 前後が測りやすい**
3. 発光量を **1/1（フル）** に設定
4. ISOを **100** に設定
5. F値を変えながら撮り、**ちょうど適正になったF値**を見つける
6. 設定タブ →「テスト撮影で校正」に、距離・F値・ISO・発光量を入力

これだけで k が更新され、以降すべての計算が実機に合います。

## 例

200Ws、距離3m、ISO100、フル発光で **F11 が適正**だった場合、

```
実測GN = 11 × 3 = 33
k = 33 ÷ √200 = 2.33
```

既定の 4.0 から 2.33 に下がりました。**約1.5段ぶん**の差です。
校正前は「到達5.0m」と出ていたものが実際は3.0m だったことになります。

## モディファイアごとに校正する

校正値は**プロファイルごと・モディファイアごとに保存**されます。
標準リフレクターとソフトボックスで別々に校正すれば、切り替えても正確なままです。

よく使う組み合わせから順に校正していけば十分です。

# §12 計算タブの使い方

## 2つ決めて3つ目を出す

F値・SS・ISO のうち**2つの鍵アイコンを閉じる**と、残り1つが自動で計算されます。
鍵を開けて別の組み合わせに変えれば、そちらが計算されます。

シーンのEVはかんたんタブから引き継がれます。直接入力もできます。

## 等価露出の一覧

下部に**同じ明るさになる組み合わせ**が並びます。F値の開放側から絞り側へ、1段刻みです。

各行に小さな警告アイコンが付きます。

| アイコン | 意味 |
| --- | --- |
| 手ブレ | この行のSSでは手ブレしやすい |
| 回折 | F値が絞りすぎで解像が落ちる |
| 高感度 | ISOが実用上限に近い |

**アイコンが付いていない行から選ぶのが安全です。** 現在の主案の行はハイライトされます。

# §13 <a id="help-warnings"></a>警告の読み方

警告には3段階あります。**色だけでなくアイコンと文言でも区別**しています。

| レベル | 意味 | 対応 |
| --- | --- | --- |
| **情報**（info） | 知っておくとよいこと | 対応不要。読み流してよい |
| **注意**（warn） | 撮れるが品質に影響する | 許容できるか判断する |
| **警告**（alert） | このままでは撮れない | 対応が必要 |

## 「○段」の意味

警告には必ず**何段足りない／超過しているか**が入ります。これは対処の量を示しています。

- 「2段足りません」→ ISOを2段上げる、F値を2段開ける、距離を半分にする、のいずれか
- 「5段超過」→ 5段の減光が必要

**段数が分かれば、どの手段を何段分使うかを自分で組み立てられます。**
「足りません」だけでは動けませんが、「2段」なら判断できます。

## <a id="help-warn-shake"></a>手ブレしやすい速度です

SSが手ブレ限界（1÷焦点距離×補正段数）より遅い状態です。
三脚を使う、ISOを上げてSSを稼ぐ、焦点距離を短くする、のいずれかで解決します。

**不足が1/3段未満のときは警告を出しません。** 1÷焦点距離の法則自体が±1段程度の精度しかなく、
わずかな不足で警告するのは意味のある精度ではないためです。

## <a id="help-warn-motion"></a>被写体が流れます

被写体の動きに対してSSが足りません。表示された速度以上にしてください。
流し撮りなど**意図的にブレさせたい場合は無視してかまいません。**

## <a id="help-warn-light-short"></a>光量が足りません

ISOを上限まで上げ、F値を開放まで開けても明るさが足りない状態です。
三脚を使ってSSを稼ぐ、より明るいレンズを使う、ストロボを使う、のいずれかが必要です。

実用ISO上限は設定で変えられます。ノイズを許容できるなら上げてください。

## <a id="help-warn-diffraction"></a>回折で解像が落ち始めます

F11 を超えると、絞りすぎによる回折で全体の解像が下がります。
被写界深度を稼ぐために必要な場合はそのまま撮ってかまいません。**情報レベルの通知です。**

## <a id="help-warn-high-iso"></a>ノイズが目立ち始める領域です

実用ISO上限の半分を超えました。撮れますが、暗部のノイズが見えてきます。

## <a id="help-warn-tripod"></a>三脚推奨

SSが1/2秒以上です。手持ちでは厳しい速度です。

## <a id="help-warn-flash-strong"></a>光が強すぎます

最小発光量まで下げても被写体が明るすぎる状態です。
**距離を離す**（2倍離せば2段下がる）、ISOを下げる、F値を絞る、NDを追加する、のいずれかで解決します。

## <a id="help-warn-flash-short"></a>ストロボが足りません／光が届きません

フル発光でも光量が足りない状態です。表示された段数ぶん、以下のいずれかで稼ぎます。

| 手段 | 効果 |
| --- | --- |
| 距離を半分にする | 2段 |
| ISOを2倍にする | 1段 |
| F値を1段開ける | 1段 |
| NDを外す | ND の段数ぶん |
| モディファイアを外す | 1〜2.5段 |

**距離が最も効きます。** 6mから3mに詰めるだけで2段稼げます。

## <a id="help-warn-recycle"></a>チャージが追いつきません

発光量が1/2以上です。フル発光に近いとチャージに時間がかかり、連写では発光しない駒が出ます。
1コマずつ撮るか、距離を詰めて発光量を下げてください。

# §14 <a id="help-offline"></a>オフラインで使う

## ホーム画面に追加する

Safari で開いて、共有ボタン →「ホーム画面に追加」。
これでアプリのように起動し、**電波がなくても全機能が動きます。**

追加せずブラウザで使っても動きますが、アドレスバーで画面が狭くなります。

## 通信について

このアプリは**一切通信しません。** 計算はすべて端末内で行われ、入力した内容はどこにも送られません。
機内モードでも通常どおり使えます。

## 更新のされかた

新しいバージョンが用意されると、次にオンラインで開いたときにヘッダーへ
**「新しいバージョンがあります ［更新］」** というバーが出ます。

**押すまで更新されません。** 計算中に画面が勝手に切り替わることはありません。
現場では押さず、帰ってから押してかまいません。

## 設定の保存先

機材設定や校正値は**端末内**に保存されます。バックアップも同期もされません。

- ブラウザの履歴やサイトデータを消すと設定も消えます
- プライベートブラウズでは保存されません（計算は使えます）
- 別の端末には引き継がれません

校正値は入れ直すのに時間がかかるので、**k の値を手元にメモしておく**と安心です。

# §15 <a id="help-troubleshoot"></a>こんなときは

## 計算結果が実際とズレる

まず**シーンの微調整**を確認してください。シーンEVは±1段の目安です。
1段暗かったなら微調整を +1.0 にすれば以降は合います。

ストロボがズレる場合は**校正**（§11）をしてください。未校正だと1〜1.5段ズレることがあります。

## ストロボの到達距離が実際より長く出る

未校正の可能性が高いです。「推定値」バッジが出ていないか確認してください。
§11 の手順で校正すると合います。

## HSSにすると計算より暗い

HSS基準損失が実機と合っていません。設定タブで値を上げてください（既定2.0、範囲1.0〜2.5）。
「1段暗い」なら基準損失を1段増やします。

## 設定が保存されない

プライベートブラウズになっていないか確認してください。
画面に「設定を保存できません」と出ている場合、計算機能は使えますが設定は毎回初期値に戻ります。

## 更新バーが出ない

更新は**オンラインで開いたとき**に検出されます。オフラインのままでは出ません。
一度電波のある場所で起動してください。

## 画面が白いまま／数字が出ない

ホーム画面のアイコンを長押しして削除し、Safari から開き直して再度追加してください。
設定は残ります（同じ保存領域を使うため）。

## 入力した数値が勝手に変わる

範囲外の値は自動で範囲内に丸められます。「8〜1200mm の範囲に丸めました」のような通知が出ます。
入力を拒否せず丸める設計です。
